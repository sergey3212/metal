# Описание проекта
Нужно разработать простой и понятный сайт для производственной мастерской. Основная задача сайта — служить точкой входа для клиентов из рекламы (соцсети, визитки, Яндекс реклама) и дать возможность быстро связаться для обсуждения заказа.
Сайт не должен быть перегружен текстами. Основной упор — на фотографии работ и понятную подачу направлений деятельности.

# Тематика бизнеса
Производство изделий из металла и профильной трубы:
- металлические лестницы
- перила и ограждения
- навесы, козырьки
- беседки
- металлокаркасы для мебели
- изделия по чертежам заказчика
- небольшие металлоконструкции

# Основные направления, на которые нужно сделать акцент
- Лестницы и ограждения
- Навесы и козырьки
- Металлоконструкции / изделия по чертежам

# Что должно быть на сайте
- современный аккуратный дизайн
- адаптация под мобильные устройства
- галерея выполненных работ
- форма заявки
- кнопка связи (телефон / макс/ Tg)
- блок преимуществ (собственное производство, покраска и т.п.)

# Главная цель сайта
Чтобы посетитель быстро понял чем мы занимаемся, какие изделия делаем и мог легко связаться.
Тексты можно написать кратко на основе описания деятельности.
