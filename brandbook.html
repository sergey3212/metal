6. Анимации и эффекты

6.1 Glitch Effect (Эффект помех)

Текст с эффектом глитча

Эффект цифровых помех с подёргиванием текста и изменением размера отдельных слов. Используется в главном заголовке Hero-секции.

Демонстрация эффекта

Текст периодически дёргается (3 серии рывков за 5 секунд), слова случайно изменяют размер на ±25%

Изделия из металла Изделия из металла Изделия из металла
/* HTML структура */ <div class="glitch-wrapper"> <span class="glitch" data-text="Изделия из металла"> <span class="glitch-word">Изделия</span> <span class="glitch-word">из</span> <span class="glitch-word">металла</span> </span> </div>
/* CSS Glitch Effect */ .glitch { position: relative; color: var(--color-primary); display: inline-flex; gap: 0.3em; animation: glitch-shake 5s infinite; } .glitch::before, .glitch::after { content: attr(data-text); position: absolute; top: 0; left: 0; width: 100%; height: 100%; } /* Оранжевый слой смещения */ .glitch::before { color: var(--color-primary); z-index: -1; animation: glitch-anim-1 0.5s infinite linear; } /* Тёмно-серый слой смещения */ .glitch::after { color: var(--color-dark); z-index: -2; animation: glitch-anim-2 0.5s infinite linear; } /* Расписание рывков (5 секунд) */ @keyframes glitch-shake { 0%, 15%, 100% { transform: translate(0, 0); } 16.5% { transform: translate(-18px, 6px); } 18% { transform: translate(18px, -6px); } 19.5% { transform: translate(-18px, -6px); } 21% { transform: translate(18px, 6px); } /* 1-я серия рывков (0.75–1.05 сек) */ 50% { transform: translate(0, 0); } 51.5% { transform: translate(-12px, 12px); } 53% { transform: translate(12px, -12px); } 54.5% { transform: translate(-12px, -10px); } 56% { transform: translate(0, 0); } /* 2-я серия рывков (2.5–2.8 сек) */ 75% { transform: translate(0, 0); } 76.5% { transform: translate(-14px, -10px); } 78% { transform: translate(14px, 10px); } 79.5% { transform: translate(0, 0); } /* 3-я серия рывков (3.75–3.975 сек) */ }

6.3 GSAP Анимации (ScrollTrigger)

Анимация при скролле

Карточки направлений и заголовки секций анимируются при появлении в области видимости с помощью GSAP ScrollTrigger.

Параметры анимации

Каждая карточка появляется с задержкой 0.2s, с эффектом отскока

/* GSAP Timeline для карточек направлений */ const tl = gsap.timeline({ scrollTrigger: { trigger: '.directions', start: 'top 80%', end: 'top 20%', toggleActions: 'play none none reverse', once: false } }); /* Анимация каждой карточки */ directions.forEach((direction, index) => { gsap.set(direction, { opacity: 0, y: 100, rotationY: -15, scale: 0.9 }); tl.to(direction, { duration: 0.8, opacity: 1, y: 0, rotationY: 0, scale: 1, ease: 'back.out(1.7)', delay: index * 0.2 }); });
