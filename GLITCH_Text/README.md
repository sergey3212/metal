# Glitch Text Effect v2

Эффект глитча с подергиванием текста и **изменением размера отдельных слов**.

## 📋 Быстрый старт

### 1. Подключите CSS

```html
<link rel="stylesheet" href="glitch.css">
```

### 2. Добавьте HTML-структуру

```html
<div class="glitch-wrapper">
    <span class="glitch" data-text="ВАШ ТЕКСТ">
        <span class="glitch-word">СЛОВО1</span>
        <span class="glitch-word">СЛОВО2</span>
        <span class="glitch-word">СЛОВО3</span>
    </span>
</div>
```

**Важно:** 
- Атрибут `data-text` должен содержать тот же текст, что и внутри
- Каждое слово должно быть обёрнуто в `<span class="glitch-word">`

### 3. Подключите JavaScript

```html
<script src="glitch-words.js"></script>
```

Скрипт автоматически инициализируется после загрузки страницы.

## ⏱️ Тайминги анимации

### Основной цикл (5 секунд)

| Время | % ключа | Описание |
|-------|---------|----------|
| 0–0.75 сек | 0–15% | Текст стоит на месте |
| **0.75–1.05 сек** | **15–21%** | **1-я серия рывков** (4 движения + 4 изменения слов) |
| 1.05–2.5 сек | 21–50% | Текст стоит на месте |
| **2.5–2.8 сек** | **50–56%** | **2-я серия рывков** (3 движения + 3 изменения слов) |
| 2.8–3.75 сек | 56–75% | Текст стоит на месте |
| **3.75–3.975 сек** | **75–79.5%** | **3-я серия рывков** (2 движения + 2 изменения слов) |
| 3.975–5 сек | 79.5–100% | Текст стоит на месте |

### Эффект изменения размера слов

Во время каждой серии рывков:

1. **Выбирается случайное слово** из текста
2. **Случайно увеличивается на 25%** (`scale(1.25)`) или **уменьшается на 25%** (`scale(0.75)`)
3. Через **150мс** возвращается к нормальному размеру

**Пример для текста "Изделия из металла" (3 слова):**

| Серия | Время | Кол-во изменений | Какие слова могут измениться |
|-------|-------|------------------|------------------------------|
| 1-я | 0.75–1.05 сек | 4 | "Изделия", "из", или "металла" (случайно) |
| 2-я | 2.5–2.8 сек | 3 | Любое из 3 слов (случайно) |
| 3-я | 3.75–3.975 сек | 2 | Любое из 3 слов (случайно) |

## 🎨 Как это работает

### CSS-анимации:

1. **`glitch-shake`** (5 сек) — подёргивание основного текста
2. **`glitch-anim-1`** (0.5 сек) — мерцание оранжевого слоя
3. **`glitch-anim-2`** (0.5 сек) — мерцание тёмно-серого слоя

### JavaScript-эффект:

- `initGlitchWords()` — находит все элементы `.glitch` и запускает анимацию
- `runGlitchCycle()` — управляет 5-секундным циклом анимации
- `changeWordSizes()` — выбирает случайное слово и меняет его размер

## ⚙️ Настройка

### Изменить амплитуду изменения размера

В `glitch-words.js`, функция `changeWordSizes()`:

```javascript
const scale = increase ? 1.25 : 0.75; // Поменяйте значения
```

Например:
```javascript
const scale = increase ? 1.5 : 0.5; // +50% / -50%
```

### Изменить длительность возврата размера

```javascript
setTimeout(() => {
    word.style.transform = 'scale(1)';
}, 150); // Поменяйте 150 на нужное значение в мс
```

### Изменить интервал между изменениями в серии

В функции `changeWordSizes()`:

```javascript
setTimeout(() => {
    // ...
}, i * 150); // Поменяйте 150 на интервал между изменениями
```

### Изменить количество изменений в серии

В функции `runGlitchCycle()`:

```javascript
setTimeout(() => {
    changeWordSizes(words, 4); // Поменяйте 4 на нужное число
}, 750);
```

### Изменить тайминги серий

В функции `runGlitchCycle()`:

```javascript
setTimeout(() => {
    changeWordSizes(words, 4);
}, 750); // Поменяйте 750 на нужное время в мс
```

### Изменить длительность цикла

В функции `runGlitchCycle()`:

```javascript
setTimeout(() => {
    runGlitchCycle(words);
}, 5000); // Поменяйте 5000 на нужное время в мс
```

## 🔧 Устранение проблем

### Слова не меняют размер
- Проверьте, что `glitch-words.js` подключён
- Откройте консоль (F12) и проверьте наличие ошибок
- Убедитесь, что у элементов есть класс `.glitch-word`

### Текст не подёргивается
- Проверьте, что `glitch.css` подключён
- Убедитесь, что у `.glitch` есть `animation: glitch-shake 5s infinite`

### Слои не видны
- Проверьте CSS-переменные `--color-primary` и `--color-dark`
- Убедитесь, что `data-text` совпадает с содержимым элемента

### Эффект слишком резкий
- Увеличьте длительность анимации в CSS
- Уменьшите значения `scale` в JS

### Эффект слишком медленный
- Уменьшите длительность цикла в `runGlitchCycle()`
- Уменьшите интервал возврата размера (150мс)
