# PRD: Лендинг для мастерской металлоизделий

## 1. Введение/Обзор

**Продукт:** Одностраничный сайт-лендинг для производственной мастерской, специализирующейся на изделиях из металла и профильной трубы.

**Проблема:** У мастерской нет современной онлайн-витрины, которая бы эффективно конвертировала трафик из рекламы (соцсети, визитки, Яндекс.Директ) в заявки. Потенциальные клиенты не могут быстро оценить компетенции и связаться для заказа.

**Решение:** Создать лаконичный, визуально ориентированный лендинг с акцентом на фото работ и простые способы связи.

**Цель:** Посетитель за 10–15 секунд понимает, чем занимается мастерская, видит примеры работ и может легко оставить заявку.

---

## 2. Цели

| № | Цель | Критерий успеха |
|---|------|-----------------|
| 1 | Конверсия посетителя в заявку | Наличие работающей формы заявки и кнопок связи |
| 2 | Демонстрация компетенций | Галерея с фото работ по 3 ключевым направлениям |
| 3 | Мобильная доступность | Корректное отображение на экранах от 320px |
| 4 | Быстрая загрузка | Время загрузки первой экранной области < 2 сек |

## 3. Пользовательские истории (User Stories)

| ID | Как... | Я хочу... | Чтобы... |
|----|--------|-----------|----------|
| US1 | Потенциальный заказчик | Увидеть примеры работ сразу на главной | Понять уровень качества без изучения текста |

## 4. Функциональные требования

### 4.1 Структура страницы

| № | Требование |
|---|------------|
| FR1 | Сайт должен состоять из одной страницы (лендинг) с якорной навигацией |
| FR2 | Страница должна содержать следующие секции: Header, Hero, Преимущества, Направления, Галерея, Форма заявки, Footer |

### 4.2 Header (шапка)

| № | Требование |
|---|------------|
| FR3 | В шапке должен быть логотип (текстовый или заглушка) |
| FR4 | В шапке должна быть навигация с якорными ссылками на секции |
| FR5 | В шапке должен быть видимый номер телефона (кликабельный для звонка) |

### 4.3 Hero (главный экран)

| № | Требование |
|---|------------|
| FR6 | Главный экран должен содержать заголовок с УТП (уникальное торговое предложение) |
| FR7 | Главный экран должен содержать подзаголовок с кратким описанием деятельности |
| FR8 | Главный экран должен содержать кнопку призыва к действию (CTA) — «Заказать расчёт» или «Связаться» |
| FR9 | Главный экран должен содержать фоновое изображение или фото работы |

### 4.4 Преимущества

| № | Требование |
|---|------------|
| FR10 | Секция должна содержать 4–6 блоков преимуществ |
| FR11 | Каждое преимущество должно иметь иконку (или заглушку) и краткий текст |
| FR12 | Примеры преимуществ: собственное производство, покраска, работа по чертежам, сроки, гарантия |

### 4.5 Направления деятельности

| № | Требование |
|---|------------|
| FR13 | Секция должна выделять 3 ключевых направления: Лестницы и ограждения, Навесы и козырьки, Металлоконструкции/изделия по чертежам |
| FR14 | Каждое направление должно иметь название, краткое описание и фото |

### 4.6 Галерея работ

| № | Требование |
|---|------------|
| FR15 | Галерея должна отображать 6–12 фотографий работ в виде сетки (grid) |
| FR16 | При клике на фото оно должно открываться в увеличенном виде (lightbox/модальное окно) |
| FR17 | Галерея должна быть адаптивной (3 колонки на десктопе, 2 на планшете, 1 на мобильном) |

### 4.7 Форма заявки

| № | Требование |
|---|------------|
| FR18 | Форма должна содержать поля: Имя, Телефон, Комментарий (опционально) |
| FR19 | Форма должна иметь кнопку отправки |
| FR20 | Форма должна иметь базовую валидацию (обязательное поле телефона) |
| FR21 | После отправки должно отображаться сообщение об успехе или ошибке |
| FR22 | Данные формы должны отправляться на сервер/внешний сервис (настроить по месту) |

### 4.8 Footer (подвал)

| № | Требование |
|---|------------|
| FR23 | В подвале должны быть контакты: телефон, email, мессенджеры (Telegram, WhatsApp) |
| FR24 | В подвале должна быть ссылка на политику конфиденциальности (заглушка или текст) |

### 4.9 Адаптивность

| № | Требование |
|---|------------|
| FR25 | Сайт должен корректно отображаться на экранах шириной от 320px |
| FR26 | На мобильных устройствах навигация должна сворачиваться в «гамбургер»-меню |
| FR27 | Кнопки связи (телефон, мессенджеры) должны быть крупными и удобными для тапа |

## 6. Дизайнерские решения

| Аспект | Требование |
|--------|------------|
| Стиль | Современный, минималистичный, индустриальный |
| Цветовая гамма | Металлик/серый как основной, акцентный цвет — оранжевый/синий/красный (на выбор разработчика) |
| Типографика | Читаемые шрифты без засечек (например, Inter, Roboto, Montserrat) |
| Изображения | Акцент на реальные фото работ, минимальное количество стоковых изображений |
| Иконки | Простые линейные или залитые иконки (можно использовать библиотеки: Heroicons, FontAwesome, Material Icons) |

---

## 7. Технические соображения

| Аспект | Рекомендация |
|--------|--------------|
| Фронтенд | HTML5, CSS3, ванильный JavaScript (или легкий фреймворк по выбору разработчика) |
| Адаптивность | Mobile-first подход, CSS Grid/Flexbox |
| Форма заявки | Интеграция с Formspree, EmailJS, Telegram API или простой PHP-обработчик |
| Хостинг | Любой статический хостинг (Netlify, Vercel, GitHub Pages) или классический хостинг |
| Производительность | Оптимизация изображений (WebP, lazy loading), минификация CSS/JS |
| SEO | Базовая разметка: title, meta description, alt для изображений |

| Метрика | Целевое значение |
|---------|------------------|
